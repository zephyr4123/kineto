Snug 宣传片的定位（主人 2026-11-13 看完第三版后纠正）：

- Snug 是给 UU远程 做的辅助插件，让 UU远程 在 iPhone 上更好用（尺寸按 iPhone 17 Pro Max 优化）；不是新的远程软件。slogan 先定「Make UU Remote Better」，同日改为「Make UU Remote Native on iPhone」（主人原话 "Make UU remote native in iphone"，润色了介词）。
- 核心主旨是 **mobile native**：在手机上像用手机一样操作远程的 Mac（单指滚动、长按选字复制、长按调右键菜单、横条回列表）。原版 UU远程 的手势照触控板来（双指才滚动，复制要调出电脑键盘按组合键），这是要讲的对比点。
- 不拉踩：不比 AI 自带的远程控制（Claude Remote Control、Codex）、不说 UU 自带终端的不是、不只挑 UU 的坏处。主人原话：「就好像专门找茬一样：人家好的你不说，就只挑坏的」「非常让人反感」。
- 负面对比要有，但要温和、讲事实，落在「桌面的操作方式搬到手机上的落差」，不是「UU 不行」。
- 开场不能一上来就甩问题，要有过渡。
- 「惯性滑动」这类实现细节观众听不懂，不当卖点讲。

**Why:** 第三版的三个痛点（太小、只连自家 AI、终端接不上）被主人认为定位错了、像甩臭脸。
