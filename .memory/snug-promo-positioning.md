Snug 宣传片的定位（主人 2026-11-13 看完第三版后纠正）：

- Snug 是给 UU远程 做的辅助插件，让 UU远程 在 iPhone 上更好用（尺寸按 iPhone 17 Pro Max 优化）；不是新的远程软件。slogan 先定「Make UU Remote Better」，同日改为「Make UU Remote Native on iPhone」（主人原话 "Make UU remote native in iphone"，润色了介词）。
- 核心主旨是 **mobile native**：在手机上像用手机一样操作远程的 Mac（单指滚动、长按选字复制、长按调右键菜单、横条回列表）。原版 UU远程 的手势照触控板来（双指才滚动，复制要调出电脑键盘按组合键），这是要讲的对比点。
- 不拉踩：不比 AI 自带的远程控制（Claude Remote Control、Codex）、不说 UU 自带终端的不是、不只挑 UU 的坏处。主人原话：「就好像专门找茬一样：人家好的你不说，就只挑坏的」「非常让人反感」。
- 负面对比要有，但要温和、讲事实，落在「桌面的操作方式搬到手机上的落差」，不是「UU 不行」。
- 开场不能一上来就甩问题，要有过渡。
- 「惯性滑动」这类实现细节观众听不懂，不当卖点讲。
- **通篇紧扣一个主题：「让 UU远程 在 iPhone 上接近原生体验」**，每一段都得是这句话的证据（第四版后主人再次纠正，原话「没有扣紧主题」「方向走偏了」）。不放：与主题无关的生活场景（暂离工位、日历提醒、人在途中）、UU远程 本身的功能介绍（点开 UU、连回 Mac、键盘打字）、AI 能力（Any AI、/resume 接续会话）。
- 多窗口那段的立意是「终端 CLI、桌面 App、浏览器、笔记，不管哪类窗口，配合 Snug 都是 iPhone 原生手感」，AI 只是其中一种窗口里的内容，不是卖点。
- 手势要有实打实的对照：原版跟着触控板走，Snug 跟着手机走。对照的事实以 snug 仓库 README 的两张对比表为准（「核心体验」「手势：为触屏重新设计」：单指滑动 = 鼠标拖拽 vs 页面滚动；长按松开 = 普通点击 vs 右键菜单；切换窗口 = 在缩小的桌面里找 vs 窗口列表）。

- 落差不止手势（主人看第四版方案后补充）：原版**竖屏**上下大片黑边、只有横过来才稍微能用，**横屏**又因为字太小，滑动、拖动都不准。两头都要演出来，才衬得出 Snug 竖屏像原生 App。
- 任意窗口那段要**写字**（弹出键盘输入），「光读不写没有感染力」：终端敲命令启动 Claude、ChatGPT 里提问；每类窗口留一个就够，Notion 质感差，不用。
- 信息密度要高：不要一幕十秒只讲「窗口铺满、字号放大」这一点，几个点要融在一起；音乐快，推拉、转场要多、要有审美，不要像手机陈列柜一样一台换一台。

- 手势对照要**先演原版、再演 Snug**，不要上下两台同时演（主人看第五版后指出，2026-11-13）。上下并排加两行小字，观众会以为「装了插件就这两种特性」，中间缺过渡。每个动作先插一秒左右原版的做法，再切到 Snug，点明更接近 iPhone 原生。主人举的例子：
  - 滚动：原版像 Mac 触控板一样双指滚动，Snug 单指滚动；
  - 拷贝：原版选字和手机滚动是同一个手势，复制还得调出电脑键盘按组合键，Snug 长按就行。

  对比文字要拆成几小块，不能是一长行。

- Mac 端那段讲「开箱即用 / 安装即用」：下载一装、权限一开，之后什么都不用管（主人看第六版后纠正，2026-11-13，原话「核心是开箱即用」）。不写「Mac 端零操作」，那句没把意思说清楚。画面照 snug 仓库 README 的「安装」三步和欢迎页截图来。

- 第八版起，亮相「iPhone 专属竖屏」之后分四章，每章一张章节卡（总分，见 [[video-feature-structure]]）：01 原生手势（单指滚动、长按拷贝）、02 流转自如（指示条 · 窗口列表）、03 万窗皆宜（终端 · App · 浏览器）、04 开箱即用（Mac 端 · 一次授权，含断开即复原）。底部那个元素按 README 叫「底部指示条」，不叫「横条」。

**Why:** 第三版的三个痛点（太小、只连自家 AI、终端接不上）被主人认为定位错了、像甩臭脸；第四版开头的暂离工位、UU REMOTE、BUILT FOR DESKTOP 被认为像在给 UU远程 拍宣传片，中段 ANY AI 跑偏。

**How to apply:** 改 snug-promo 的文案和段落前先对照这几条；每加一段先问「这段证明了 iPhone 原生手感的哪一点」，答不上就不放。画面文字同时守 [[video-caption-copy]]。
