宣传片画面上的字（英文主角词下面的中文、小标签、画面里的说明行、落版标语）一律写成书面语短词：

- 能用短词就不用句子，几个短词用空格或「·」隔开，例如「整屏缩放 · 字迹难辨」「会话恢复 · 上下文完整」。
- 不写主谓宾齐全的句子，也不写平淡的口语。主人点名的反例：「Mac 上的 AI 还在干活」「人要走开 想用手机接着盯」「单指一滑 只会拖选一片」。
- 界面里本来就有的字（App 里的内容、GitHub 仓库描述、通知内容）照实，不在此列。

排版（snug-promo 第五版后主人指出，2026-11-13）：

- **中文是信息主角**：面向用户传达信息的是中文，字号要大、颜色要深；英文只做小标。英文大标题配中文小字是「本末倒置」。
- **对比度不低于 4.5:1**（苹果的要求）：浅灰字、亮蓝小字、青色渐变上的白字都不达标。配色要按画面里最暗的底来算，出片前量一遍。
- **不要瀑布式竖排**：说明文字别全堆在屏幕中间一行行往下排；用箭头从手机旁边引出来，指着它说的那块画面。
- **长的对比文字拆成小块**：例如步骤做成一个个带序号的小标签，手指点到哪步弹出哪步，不写成一整行「A → B → C → D」。

措辞要凝练、有审美（snug-promo 第七版后主人指出，2026-11-13）：

- 标题、章节名用凝练的书面语，四字格最好，例如「原生手势」「流转自如」「万窗皆宜」「开箱即用」。
- 「所有窗口皆可竖屏」这种把意思平铺直叙出来的写法，主人认为太口语，要打磨成高审美的书面语。
- 演示里的标题同一组要对仗，例如「双指滚动 / 单指滚动」「缩略图切换 / 轻点切换」，副标「同 Mac 触控板 / 同 iPhone」。

**Why:** snug-promo 第三版改稿时主人指出：口语和完整句子在画面上「显得非常 low」。这条在第一版就交代过（书面语、短词），新加的场景又写回了口语，被二次指出。

第五版的问题：英文主角词 150 号、中文 50 号灰字，原版那行标签灰字对比度只有 3.15:1。主人的原话是，字幕和画面是这种片子「唯二能够传达信息的点」，画面又切得快，字太小观众就「不知所以然」。

**How to apply:** 写完任何一条画面文字，先问自己「能不能砍成两三个短词」；出片前把全部画面文字列一遍逐条过。排字时先定中文的位置和大小，再放英文小标；能指着画面说的，就用箭头标注。出片前在静帧里量字幕区域的对比度。配合 [[video-ui-fidelity]] 一起自查。
