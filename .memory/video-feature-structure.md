宣传片里依次讲几个 feature 时（主人看 snug-promo 第七版后提出，2026-11-13）：

- **总分结构**：每一章开头单独占满一屏，先点明这一章讲什么（总），再进具体演示（分）。不要把 feature 名和演示混在一屏里平铺，否则每个点一样重，观众不知道重点在哪，「每个都平均讲，就等于每个都没讲透」。
- **章节卡不能千篇一律**：同一个版式复制四次就像 PPT。每张卡的底（颜色、明暗、纹理）、四周的元素、标题的位置、进场和退场的方式都要不一样，只保留章节号这类小件做统一。
- 章节卡最好用画面本身说明这一章：手势那章演指尖涟漪和手势，切窗口那章演多任务卡片流，「所有窗口」那章演满天窗口飞进手机。
- 英文小标只放在章节卡上，演示里只留中文标题，主次一眼分开。

**Why:** 第七版里 NATIVE SCROLL、NATIVE SWITCH、ANY WINDOW 这些 feature 和演示混在一起，没有承接页。我提出章节卡可能像 PPT 的风险后，主人要求每张卡呈现方式都不同、背景和环绕元素要丰富。

**How to apply:** 排 feature 段落时先列出章节和每章下面的演示，再给每张章节卡单独定底色、主视觉和转场，四张放在一起比一比，不能看出是同一个模板。章节卡要落在音乐的段落点上，时长 2 秒左右（演示再长一点的卡可以做成小场景）。章节名的写法守 [[video-caption-copy]]，snug-promo 的具体章节见 [[snug-promo-positioning]]。
